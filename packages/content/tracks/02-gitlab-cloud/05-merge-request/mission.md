# Missão Prática: Abrindo um Merge Request

Abra uma solicitação de mesclagem para unir a `feat/adiciona-membro` na `main`.

### Passos:
1. No GitLab, vá em **Code > Merge Requests > New Merge Request**.
2. Escolha **Source branch:** `feat/adiciona-membro` e **Target branch:** `main`.
3. Na descrição do MR, escreva:
   ```text
   Closes #1
   ```
4. Clique em **Create merge request** e valide na plataforma.

### Critério de Aceite
Um Merge Request aberto da branch `feat/adiciona-membro` para `main` referenciando o fechamento da Issue.

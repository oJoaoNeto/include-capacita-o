# Cápsula Teórica: Merge Request (MR)

O **Merge Request** é o coração da colaboração em software. É o pedido formal para integrar o código da sua branch na `main`.

Ele permite que outros desenvolvedores da EJ leiam as alterações linha por linha, façam sugestões de melhoria e aprovem o código antes dele ser publicado.

> [!TIP]
> Se você escrever `Closes #1` na descrição do MR, o GitLab fechará a Issue #1 automaticamente quando o MR for mesclado!

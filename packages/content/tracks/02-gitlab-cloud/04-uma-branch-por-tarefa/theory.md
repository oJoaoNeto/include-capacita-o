# Cápsula Teórica: Uma Branch por Tarefa

No fluxo profissional do GitLab, **nunca** enviamos commits diretamente para a branch `main`. Para cada Issue aberta, criamos uma branch temática dedicada.

Ao nomear a branch, usamos prefixos claros:
- `feat/nome-da-feature`: Para novas funcionalidades.
- `fix/nome-do-bug`: Para correções de falhas.

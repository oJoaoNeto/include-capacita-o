# Cápsula Teórica: Code Review e Feedback

O Code Review (Revisão de Código) não é uma prova ou bronca: é uma oportunidade de aprendizado mútuo e garantia de qualidade.

Quando um revisor pede um ajuste no seu MR, você **não** fecha o MR nem cria outra branch. Você simplesmente faz a alteração pedida no seu computador, faz um novo commit e envia o push na **mesma branch**! O Merge Request no GitLab se atualizará sozinho.

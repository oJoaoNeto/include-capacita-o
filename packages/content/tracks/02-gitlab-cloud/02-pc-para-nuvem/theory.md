# Cápsula Teórica: Do PC para a Nuvem (push)

Até agora todo o trabalho esteve guardado apenas no seu computador. Para que o restante da equipe da EJ possa colaborar, enviamos nosso histórico para o repositório remoto no GitLab.

### Comandos Essenciais
| Ação | Comando |
| :--- | :--- |
| Vincular repositório remoto | `git remote add origin git@gitlab.com:usuario/repo.git` |
| Enviar commits | `git push -u origin main` |

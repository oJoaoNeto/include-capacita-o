# Missão Prática: Do PC para a Nuvem

Envie os commits do seu repositório de treino local para o seu repositório de treino no GitLab.

### Passos:
1. Copie a URL do seu repositório de treino exibida no topo desta página.
2. No seu terminal local, adicione o controle remoto e envie a branch `main`:
   ```bash
   git remote add origin <URL-DO-SEU-REPO>
   git push -u origin main
   ```
3. Clique no botão **Verificar Missão** na interface web.

### Critério de Aceite
O GitLab deve confirmar a existência da branch `main` contendo os commits do seu repositório local.

# Missão Prática: Criando uma Issue

Abra sua primeira tarefa no seu repositório de treino no GitLab.

### Passos:
1. Acesse o seu repositório de treino no GitLab.com.
2. No menu lateral esquerdo, clique em **Plan > Issues > New Issue**.
3. Defina o título da Issue como:
   ```text
   Adicionar novo membro ao projeto
   ```
4. **Muito importante:** No campo **Assignee**, atribua a issue a você mesmo!
5. Clique em **Create issue** e volte aqui para clicar em **Verificar Missão**.

### Critério de Aceite
A API do GitLab deve encontrar uma Issue aberta com o título especificado e com você como assignee.

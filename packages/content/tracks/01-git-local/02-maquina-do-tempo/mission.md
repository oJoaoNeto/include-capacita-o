# Missão Prática: Criando a Máquina do Tempo

Transforme a pasta atual do seu exercício em um repositório Git.

### Passos:
1. Certifique-se de estar na pasta do exercício.
2. Inicialize o repositório com o comando `git init`.
3. Execute a verificação:
   ```bash
   npx ej-cap verify
   ```

### Critério de Aceite
A pasta oculta `.git` deve existir e o comando `git status` deve reconhecer a pasta como um repositório Git ativo.

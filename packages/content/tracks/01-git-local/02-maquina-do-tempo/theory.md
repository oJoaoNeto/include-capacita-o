# Cápsula Teórica: Criando a Máquina do Tempo

Qualquer pasta comum do seu computador pode se transformar em um repositório Git. Ao inicializar o Git em uma pasta, ele cria um diretório oculto especial chamado `.git/`.

> [!IMPORTANT]
> A pasta `.git/` guarda todo o histórico de versões, commits e branches. Se você apagar essa pasta, o repositório volta a ser apenas uma pasta comum e o histórico é perdido!

### Comandos Essenciais
| Ação | Comando |
| :--- | :--- |
| Inicializar repositório | `git init` |
| Verificar estado do repositório | `git status` |

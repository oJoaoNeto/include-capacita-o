# Missão Prática: Criando uma Branch

Crie uma ramificação paralela chamada `feat/treino` e navegue até ela.

### Passos:
1. Execute o comando para criar e trocar para a branch:
   ```bash
   git switch -c feat/treino
   ```
2. Valide executando:
   ```bash
   npx ej-cap verify
   ```

### Critério de Aceite
A branch ativa indicada pelo comando `git branch --show-current` deve ser `feat/treino`.

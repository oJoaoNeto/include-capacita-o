# Cápsula Teórica: Universos Paralelos (branch)

Imagine que a branch principal (`main`) é a linha do tempo sagrada do software em produção. Quando você vai desenvolver uma nova funcionalidade, você nunca mexe diretamente nela: você cria um universo paralelo, uma **branch** (*ramificação*).

Assim, se você quebrar tudo, a versão estável da `main` permanece intacta!

### Comandos Essenciais
| Ação | Comando Moderno | Comando Tradicional |
| :--- | :--- | :--- |
| Criar e entrar na branch | `git switch -c nome-da-branch` | `git checkout -b nome-da-branch` |
| Listar branches | `git branch` | `git branch` |

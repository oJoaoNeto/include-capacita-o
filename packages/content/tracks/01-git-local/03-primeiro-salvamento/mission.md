# Missão Prática: Primeiro Ponto de Salvamento

Crie seu primeiro commit oficial no repositório.

### Passos:
1. Crie um arquivo chamado `README.md` com qualquer texto descritivo.
2. Adicione o arquivo à área de preparação com `git add README.md`.
3. Crie o commit com uma mensagem: `git commit -m "docs: adiciona README inicial"`.
4. Valide rodando:
   ```bash
   npx ej-cap verify
   ```

### Critério de Aceite
O histórico local (`git log`) deve conter ao menos 1 commit registrado e o status de trabalho (`git status`) deve estar limpo.

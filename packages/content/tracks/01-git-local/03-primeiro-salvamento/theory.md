# Cápsula Teórica: Primeiro Ponto de Salvamento

No Git, salvar arquivos é um processo em dois passos:
1. **Área de Preparação (Staging Area / Index):** Você escolhe quais arquivos entrarão no salvamento com `git add`.
2. **Ponto de Salvamento (Commit):** Você registra a foto definitiva do código com uma mensagem explicativa usando `git commit -m "mensagem"`.

> [!TIP]
> Boas mensagens de commit dizem **o que** foi feito de maneira clara (ex: `feat: adiciona arquivo de apresentacao`).

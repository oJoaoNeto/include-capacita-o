# Cápsula Teórica: Identidade no Git

Antes de salvar qualquer alteração, o **Git** precisa saber quem é o autor por trás das linhas de código. Pense no Git como um cartório digital: cada documento assinado precisa conter o nome e o contato do responsável.

> [!NOTE]
> **Git vs GitLab:** O Git é a ferramenta instalada no seu computador que grava o histórico. O GitLab é o serviço na nuvem onde você compartilha esse histórico com o restante do time da EJ.

### Comandos Essenciais
| Ação | Comando |
| :--- | :--- |
| Definir seu nome | `git config --global user.name "Seu Nome Completo"` |
| Definir seu e-mail | `git config --global user.email "seu.email@empresa.com"` |
| Conferir configurações | `git config --list` |
